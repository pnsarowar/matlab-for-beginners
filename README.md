# MATLAB for Beginners

A beginner friendly collection of MATLAB lessons, exercises, and engineering applications.

## About This Repository

This repository documents learning MATLAB from the fundamentals. It is designed to help students and absolute beginners learn MATLAB through simple explanations, practical examples, and exercises.

## Learning Roadmap

- [ ] MATLAB interface and basic commands
- [ ] Variables and data types
- [ ] Vectors and matrices
- [ ] Conditional statements and loops
- [ ] MATLAB functions
- [ ] Plotting and data visualization
- [ ] Engineering applications
- [ ] Introduction to convex optimization
- [ ] Optimization using CVX in MATLAB


## Repository Structure

Each topic will contain:

- A beginner friendly explanation
- MATLAB example programs
- Practice exercises
- Expected results
- Engineering applications
